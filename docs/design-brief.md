## 確定トンマナ

- **地**: 白地 + 極淡いローズ／ラベンダーのにじみ（`#FFF7FA` / `#F5F2FF`）。カードは純白、角丸 20px、影は紫寄りの極薄
- **文字**: 濃紺黒 `#1E1B2E`。補助 `#6E6785`。最弱 `#A19BB3`
- **主色**: ローズ `#FF5C8D`（CTA・選択・強調）。副色: ラベンダー `#8B7CF6`。ハイライトの文字グラデだけ ローズ→ラベンダー
- **香調8色（パステル）**: シトラス `#FFE38A` / グリーン `#BFE8C9` / フローラル `#FFC2D6` / フルーティ `#FFC8A8` / グルマン `#F1D3B6` / ウッディ `#D9C7B3` / アンバー `#F3D39B` / ムスク `#E6E2F2` — チップ・バー・タイプカードの地に使う。結果ページの地色はタイプの液体色を 12% で敷く
- **書体**: 見出し = **Zen Maru Gothic 700/900**（丸ゴ、やわらかく太い）/ 本文 = **Zen Kaku Gothic New 400/500/700** / 数字 = 同上
- **幅**: 診断・結果は **最大 560px の一列**。LP・一覧は最大 960px だが中央寄せ。PCでも一列の「アプリ感」を崩さない
- **見出し**: 太字＋サイズ差だけ。装飾線なし。セクション見出しは中央寄せ可
- **部品**: ピルチップ（高さ 32、淡色地＋濃文字）/ ピルCTA（高さ 56、ローズ、白文字、幅いっぱい）/ 選択肢ボタン（白・角丸 16・1px 淡枠、選択で ローズ塗り）/ 進捗＝「3 / 12」＋細いバー
- **結果**: 大きなタイプ絵（円・液体色の地）→「あなたの香水タイプは」→ タイプ名（大）＋読み → キャッチ → タグ（#フローラル系 #クール #ホワイトムスク）→ 調香ノート3カード → 香りのバランス（8本の横バー%）→ 本文 → 相性カード2枚 → 選び方 → 探す → 関連 → FAQ → シェア4ボタン → CTA
