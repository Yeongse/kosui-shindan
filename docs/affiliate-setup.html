1. 全体像 — サイトのどこに、何が出るか

結果ページ（/type/{slug}）の中ほどに、収益導線が2ブロック並ぶ。どちらも「PR」ラベル付き。

ブロック中身鍵になる設定
この香りを探すタイプの検索ワード2本 ×（楽天市場／Amazon）のボタン。ブランド固定をしない「ノート名検索」リンクNEXT_PUBLIC_RAKUTEN_AFFILIATE_ID
NEXT_PUBLIC_AMAZON_ASSOCIATE_TAG
自分だけの香水を作る調香体験（香水作り）の予約サイトへのボタン。URL未設定なら非表示NEXT_PUBLIC_EXPERIENCE_URL
NEXT_PUBLIC_EXPERIENCE_NAME（任意）
NEXT_PUBLIC_EXPERIENCE_LABEL（任意）
仕組み：楽天・Amazon は「検索結果ページ」へのリンクをアフィリエイト化している。商品を個別に選ばないので、リンク切れ・在庫切れが起きず、16タイプ×2本＝32本のリンクをIDひとつで一括管理できる。体験は ASP が発行する1本のリンクを差し込むだけ。

コードの該当箇所：src/lib/affiliate.ts（URL組立）、src/components/AffiliateBlock.tsx、src/components/ExperienceBlock.tsx、src/components/SiteFooter.tsx（Amazon必須表記）。

2. Amazon アソシエイト

仕組みと条件（2026年時点）

  • 登録すると「仮登録」状態でリンクを作れる。登録から180日以内に、アフィリエイト経由の適格販売（発送完了）3件を達成すると本審査が自動で始まり、合否がメールで来る。
  • 本審査ではサイトの中身も見られる。記事数が少ないサイトは落ちやすいと言われる（当サイトは診断16＋ノート8＋ガイド10＝34ページ＋LPがあるので問題ない）。
  • 報酬は商品カテゴリ別の料率（香水は「ビューティー」カテゴリ）。支払いは銀行振込またはAmazonギフト券、最低支払額あり。
  • 180日・3件が厳しい場合の代替：もしもアフィリエイト経由で Amazon 案件を使う（こちらは審査条件が異なる）。その場合はリンクの形が変わるので、src/lib/affiliate.ts の amazonSearchUrl を差し替える。

手順

  1. affiliate.amazon.co.jp で Amazon アカウントでログインし、アソシエイトに申し込む。
  2. ウェブサイト情報に https://kosui-shindan.com を登録。サイトの説明は「12問の無料香水診断。結果の香調（ノート）に合う香水を紹介」。
  3. 支払い・税務情報を入力（マイナンバー等）。
  4. 登録完了画面で トラッキングID（例 kosuishindan-22）をメモ。
  5. NEXT_PUBLIC_AMAZON_ASSOCIATE_TAG=kosuishindan-22 を設定してデプロイ（§5）。これで全結果ページの「Amazonで探す」に &tag=… が付き、フッターに必須文言が自動表示される。
  6. 自分でテストクリック→購入してはいけない（規約違反）。公開して待つ。3件達成で本審査。
  7. 本審査に通ったら、アソシエイト・セントラルの「レポート」で売上を確認。
守ること
  • サイトに 「Amazonのアソシエイトとして、香水診断 調香箋は適格販売により収入を得ています。」 を表示する（NEXT_PUBLIC_AMAZON_ASSOCIATE_TAG を設定するとフッターに自動で出る）。
  • 価格や在庫を自分のサイトに書かない（変動するため）。検索結果リンクなので元々書いていない。
  • リンクの短縮・クローキング禁止。メール／PDF／SNS のDMなどオフラインでのリンク配布禁止。
  • 自己購入・家族購入は成果にならない。

3. 楽天アフィリエイト

仕組みと条件（2026年時点）

  • 楽天IDがあれば登録でき、審査なしで即日開始。サイトURLの登録は必要。
  • 成果条件：リンクをクリックしてから24時間以内にカートに入れ、89日以内に購入完了。料率はジャンル別（香水・コスメは概ね2〜4%帯、ショップ設定により変動）。
  • 報酬は 楽天キャッシュ で支払い。月3,001円を超える月は楽天カードまたは楽天銀行との連携が必要。3ヶ月連続で月間3,001円以上あると銀行振込の申請が可能。
  • 「検索結果ページ」も、楽天の任意URLをアフィリエイト化する仕組み（どこでもリンク）でリンク化できる。当サイトはこの形式で組み立てている。

手順

  1. affiliate.rakuten.co.jp に楽天IDでログイン。
  2. 「サイト情報の登録」で https://kosui-shindan.com を登録（サイト名: 香水診断 調香箋 / ジャンル: 美容・コスメ）。
  3. 管理画面右上または「アフィリエイトID」から アフィリエイトID（xxxxxxxx.xxxxxxxx.xxxxxxxx.xxxxxxxx の4ブロック形式）をメモ。
  4. NEXT_PUBLIC_RAKUTEN_AFFILIATE_ID= にそのIDを設定してデプロイ。
  5. 確認：結果ページの「楽天市場で探す」のリンクが https://hb.afl.rakuten.co.jp/hgc/（ID）/?pc=…&m=… になっていること。クリックして楽天の検索結果に飛べばOK。
  6. 報酬の受け取り：楽天キャッシュは楽天ペイで使える。現金化したい場合は「楽天銀行連携＋3ヶ月連続3,001円以上」を満たしてから振込申請。
リンクの形（参考） 
https://hb.afl.rakuten.co.jp/hgc/{アフィリエイトID}/?pc={楽天の検索URL}&m={楽天の検索URL}
検索URL = https://search.rakuten.co.jp/search/mall/ベルガモット%20ネロリ%20香水/
この組立は src/lib/affiliate.ts の rakutenSearchUrl()。楽天側で「どこでもリンク」の仕様が変わったら、ここだけ直せば全ページに反映される。

4. 香水作成体験（調香体験）

どこと組むか

「調香体験・香水作り」を全国で予約できる主なサイトと、提携できる ASP の候補。ASP の掲載状況は変わるので、登録後に各 ASP の管理画面で「アソビュー」「じゃらん」等を検索して確認する。

予約サイト体験の量提携できる ASP（候補）備考
アソビュー！（asoview）調香体験・香水作り 30店舗超（全国）バリューコマース / A8.net / アクセストレード（情報サイトにより記載が分かれる）体験ギフト「アソビュー！ギフト」は afb で別案件。成果は予約完了（料率 5%前後という情報あり）
じゃらん遊び・体験予約調香・アロマ系ありバリューコマースリクルート系。ポイント還元との相性が良い
アクティビティジャパン調香体験ありA8.net 等（要確認）案件の有無を ASP で確認
KLOOK海外・都市部の体験自社アフィリエイト / ASP国内の調香体験は少なめ
おすすめの進め方：まず バリューコマース に登録（審査あり・数日）→「アソビュー！」と「じゃらん遊び・体験予約」に提携申請 → どちらか承認された方の「調香体験」一覧ページへのリンクを作る。 サイト側は URL を1本入れるだけで全16タイプの結果ページに出る。

手順（バリューコマースの例）

  1. バリューコマース にサイト https://kosui-shindan.com で登録（審査 1〜数日）。
  2. 管理画面「プログラム検索」で「アソビュー」を検索 → 提携申請（即時提携の場合も）。
  3. 承認後、「広告作成」→ 任意のページURLをリンク化できる機能（MyLink／マイリンク）で、アソビューの調香体験一覧 https://www.asoview.com/leisure/act0077/ をアフィリエイトリンクにする。
  4. 発行された URL をそのまま NEXT_PUBLIC_EXPERIENCE_URL= に設定。サービス名を変える場合は NEXT_PUBLIC_EXPERIENCE_NAME=アソビュー、ボタン文言は NEXT_PUBLIC_EXPERIENCE_LABEL=調香体験を探す。
  5. デプロイ後、結果ページに「自分だけの香水を作る」ブロックが出ていること、クリックで一覧ページに着くことを確認。

記事側の強化（任意・効果が大きい）

  • ガイド記事「調香体験の選び方｜香水作りはどこでできる？」を1本足し、本文中にも同じリンクを置く（src/data/guides/part-3.ts に追加するだけで公開できる）。
  • 各タイプの結果ページ文言は、タイプのトップ／ミドル／ラストのノート名を自動で差し込んでいる（例「ベルガモット、ネロリ、ホワイトムスクを手がかりに…」）ので、追加作業は不要。

5. サイトへの反映（環境変数 → デプロイ → 確認）

環境変数

# 楽天（アフィリエイトID）
NEXT_PUBLIC_RAKUTEN_AFFILIATE_ID=xxxxxxxx.xxxxxxxx.xxxxxxxx.xxxxxxxx

# Amazon（トラッキングID）— 設定するとフッターに必須文言が出る
NEXT_PUBLIC_AMAZON_ASSOCIATE_TAG=kosuishindan-22

# 香水作成体験（ASPで発行したリンク）— 未設定ならブロックごと非表示
NEXT_PUBLIC_EXPERIENCE_URL=https://ck.jp.ap.valuecommerce.com/servlet/referral?sid=…&pid=…&vc_url=https%3A%2F%2Fwww.asoview.com%2Fleisure%2Fact0077%2F
NEXT_PUBLIC_EXPERIENCE_NAME=アソビュー
NEXT_PUBLIC_EXPERIENCE_LABEL=調香体験を探す
  1. ローカル確認：プロジェクト直下の .env.local に上記を書き、npm run dev → http://localhost:3000/type/gekko を開いてボタンのリンク先を確認。
  2. 本番：Vercel の Project → Settings → Environment Variables に同じキーを登録（Production / Preview 両方）→ Redeploy。NEXT_PUBLIC_ 付きはビルド時に埋め込まれるので、値を変えたら再デプロイが必要。
  3. 確認：本番の結果ページで 3つのリンク（楽天／Amazon／体験）を実際にクリックして着地を確認。各 ASP のレポートに「クリック」が1件つけば配線完了。
計測：クリックはすべての ASP／Amazon／楽天の管理画面で見られる。サイト側の計測フック（track('affiliate_click', …)）は現在 no-op。Cloudflare Web Analytics では外部リンククリックは追えないので、成果の確認は各管理画面で行う。

6. 表記・ルール

  • PR表記（ステマ規制・2023年10月施行）：アフィリエイトリンクを含むブロックには「PR」ラベルを付ける。両ブロックとも実装済み。記事本文にリンクを置く場合も、そのセクションに「PR」または「広告を含みます」を付ける。
  • Amazon 必須文言：「Amazonのアソシエイトとして、香水診断 調香箋は適格販売により収入を得ています。」— タグ設定時にフッターへ自動表示。
  • プライバシーポリシー：楽天アフィリエイト／Amazon アソシエイト等への参加と PR 表記について記載済み（/privacy）。体験予約サービスも「など」に含まれるが、明示したければ一文足す。
  • やってはいけない：自己購入、リンクの短縮URL化、価格・在庫の断定記載、ランキングの根拠なし表示、未成年向け表現。
  • 免責：リンク先の商品・体験の品質や在庫は保証しない旨を既に about／結果ページに記載。
